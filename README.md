# 數學領地 · 我們的成長王國

React + Vite + KaTeX 的第一階段互動原型，提供繁體中文響應式介面。

## 啟動

使用 Node.js 22.12+（目前驗證版本 24.19.0）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

其他指令：`npm test` 執行遊戲邏輯測試，`npm run build` 建立 `dist/`，`npm run preview` 檢查正式建置。

## 已提供

- 12 地塊地圖（3 塊開放），農田／民居／書院選取、升級與資源扣款。
- 5 題示範數學題、KaTeX 顯示、答題回饋與解析。
- 首次答對獎勵、同題防重複領獎、每日知識石上限。
- 平日臺灣時間 07:00–17:00 的糧草產出，離線結算、容量限制。
- 本機進度保存、最近 30 筆成長紀錄、可確認的進度重設。

遊戲數值讀取 `config/game-settings.json`。完整規則與待定事項見 `docs/專案設定說明.md`。

## 原型限制

為方便體驗，答題獎勵與升級全天開放；糧草仍僅於核心時段累積並自動計入錢包，尚無獨立領取操作。使用裝置時間與 localStorage，資料可被修改，無多分頁交易保護，不適合正式學生資料。

尚未實作：登入、Supabase/RLS/RPC、教師後台、班級王國、迷霧解鎖、正式訂正驗證、進步獎勵、特殊日期及假期排程。示範題不構成正式題庫；所有答案都在前端，正式版必須改由後端判分並限制正解存取。外部字型與圖片服務均非必要依賴。

瀏覽器驗證：先啟動開發伺服器，再執行 `npm run test:smoke`。需系統 Chromium，預設 `/usr/bin/chromium`；可用 `CHROMIUM_PATH` 指定其他位置。此測試會驗證五題作答、重複領獎防護、升級、進度保存與手機寬度。
